# 褚歌工具箱

基于 Python 3 和 PySide6 的 Windows 桌面工具箱，当前版本 **v1.3.0**。

## 功能

- 视频转 GIF：调色板优化、帧率、宽度、时间范围与循环次数。
- 图片拼图：自定义网格、标题、比例、间距，导出 PNG。
- 视频切镜拆段：自动检测、切点审核与编辑，导出 MP4 / MP3 分段。
- 视频截帧与镜头表：按间隔截帧，导出 JPG 与分页镜头表。
- 文字换行：语言识别、段落保留及可选的英文翻译。
- 水印生成：可见水印、平铺、描边、投影及隐形像素水印。
- 音视频合并：替换或混合音轨、循环音频、复制视频流或 H.264 转码。

## 环境与启动

Windows，Python 3.12，FFmpeg / FFprobe。先将 FFmpeg 和 FFprobe 加入 PATH。
在项目目录执行：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe main.py
```

也可以在安装依赖后双击「启动褚歌工具箱.bat」。本仓库提供源码，不附带安装程序。

## 使用须知

- 媒体处理任务在后台运行，可切换页面；输出前选择有效的输入文件和有写入权限的目录。
- 图片拼图使用保存对话框；其他功能的同名保护以各页面提示为准。
- 音视频合并默认最长输出 15 秒，设为 0 可输出完整视频。
- 仅在点击在线翻译时，输入文本才会发送到 LibreTranslate / MyMemory；服务可能受网络、配额或服务端限制。
- 隐形水印采用简单混淆与校验，不属于强加密。压缩、缩放或截图可能破坏水印；请自行填写并妥善保存密钥。
- 公开版本不预填隐形水印密钥，水印默认输出位置为当前用户的 Pictures 文件夹，可在界面修改。
- 窗口状态及部分路径由 Qt 设置保存；运行日志写入当前用户的本地应用数据目录。

## 项目结构

- `main.py`：主窗口、七个标签页及单实例管理。
- `launch.py`、`runtime_paths.py`：启动与运行路径。
- `ui/`：界面和后台工作线程。
- `services/`：媒体、图像、文字处理逻辑。
- `tests/`：集成验证脚本；部分验证需要 FFmpeg、图形桌面或额外的本地对照素材，不能视为通用自动化测试套件。
- `assets/`：图标与图片资源。
